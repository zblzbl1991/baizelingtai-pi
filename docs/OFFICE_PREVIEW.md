# Office 文件预览

当前源码支持在项目文件、当前分支交付物、已保存成果及聊天文档附件／未发送草稿中预览 DOC、DOCX、XLS、XLSX、PPT、PPTX。打开文件即可阅读，不调用模型，也不修改原件。实际运行实例须同时更新后端、依赖和静态资源；源码完成不表示已经部署或公开发布。

## 阅读与下载

Word 和 PowerPoint 在后端转成临时 PDF，复用 PDF 阅读器的页码、缩放、适应宽度与本页文字功能。它是近似预览，字体、分页、图形和布局可能与 Word／WPS 不同，不能用于证明公文格式或最终印刷版面正确。

Excel 在浏览器独立 Worker 中解析并显示只读网格，支持工作表切换、行列分页、单元格选择、原式和已保存结果。全屏阅读移动同一组件，保留 PDF 页码／缩放或表格的工作表／分页；切文件、切线程、断连或关闭预览会清理旧请求与组件，迟到结果不覆盖新文件。

“下载”与成果“保存”始终使用对应来源的原始字节，不把阅读 PDF、表格模型或显示样式当成原件。项目文件仍是当前磁盘内容，交付物仍是原生分支可见的固定快照，已保存成果仍是独立库内副本。预览不能扩大来源访问权限；权限撤销、分支／草稿变化或文件被替换后，需要重新打开。

损坏、加密、格式不符、超预算、排队繁忙或组件不可用时，页面区分原因并提供原件下载提示；下载本身仍受原来源权限和大小限制。刷新由用户明确触发，不自动重试失败转换。接口字段、能力标志和错误码见 [Office 预览 API](API.md#office-文件预览)。

## 表格兼容范围

- 显示保存值、字符串、布尔值、错误值、数值格式与日期系统、行高、列宽和合并单元格。XLSX 还保留受支持的字体、颜色、填充、边框与对齐；XLS 的字体、边框及图形等不还原，页面提示此限制。跨页合并区域标明延续；隐藏／veryHidden 工作表和隐藏行列不显示，隐藏工作表有省略提示。
- 公式只显示文件中的原式与已保存缓存，不执行或重新计算，缓存可能过期；没有缓存时明确标记。共享／数组公式保留主原式及范围，不猜测从属单元格的展开原式。日期显示沿用工作簿的 1900／1904 系统。
- 图表、图片、嵌入对象、批注、条件格式及其他未支持对象可能省略，网格不能冒充完整还原。外部链接不跟随、不读取远程目标；超链接作为安全文字处理。宏文件不在接收范围。
- XLSX 使用有界 OPC／XML 读取，支持 Strict／Transitional 命名空间和 UTF-8／UTF-16LE／UTF-16BE XML。主部件按有效包关系定位，不要求固定文件名；声明、编码、内部类型或关系有歧义时拒绝，不猜测修复。XLS 先检查 OLE／BIFF 容器再解析。输入、实际展开字节、XML 深度／事件、工作表、坐标、单元格、样式和模型大小均有上限，主线程再次检查模型。超过预算会拒绝预览，不能通过分页绕过解析预算；原件可在权限和下载预算内下载。

预览预算的唯一配置为 [config/office-preview.json](../config/office-preview.json)，其中 `conversion` 管服务器准入、排队、输出与缓存，`spreadsheet` 管解析及页面窗口。下载／上传限额仍由各来源契约负责，不能用文件可下载推断可在浏览器解析。CSV／TSV 继续使用原有[文本表格契约](FILE_VIEWER.md#pdf表格svg-与音频)。

## 旧格式与 Agent

DOC／XLS／PPT 可上传、预览和下载；`read_document` 和 Office 工作副本编辑明确拒绝这些旧格式。需要 Agent 读取或修改时，先在办公软件中另存为 DOCX／XLSX／PPTX 再上传。网页能预览不表示模型已读取正文，也不新增在线编辑接口。附件原件与授权见[办公附件](COMPOSER_TOOLS.md#上传办公文档与-pdf)，现代格式编辑见 [Office 文档](OFFICE_DOCUMENTS.md)。

## Windows 引擎、字体与修复

Word／PPT 转换的首批目标为 Windows x64，使用固定的 LibreOffice kit 与同版本原生引擎；版本、依赖来源和完整发行闭包见[依赖约定](development/DEPENDENCIES.md#office-预览依赖)。需要 Node 22.19.0 或更高版本，普通安装仍推荐 Node 22.x。转换不要求安装 Microsoft Office，也不会自动改用系统 LibreOffice 或另一种引擎。

统一安装入口 `node scripts/install.cjs` 构建本地表格资源。在已声明支持的 Windows x64 上，它还执行引擎完整性校验与隔离文档转换健康探针。缺失／损坏的预览组件使首次安装报告 Office 预览降级，工作台仍可启动；这不代表其他安装失败可以忽略。Windows x64 更新候选和便携构建要求转换探针成功后才可完成或激活，失败保留原运行版；组件缺失、完整性失败和健康故障均不放宽。

其他系统或架构尚未声明原生 Word／PPT 转换支持。共享平台策略会报告 `office_unsupported` 和实际平台，不解析 Windows 引擎、不执行其健康探针，也不要求 Windows 运行库；不会仅因这一可选能力未支持而阻断其他工作台安装／更新。表格浏览器资源仍会准备，预览仍需来源与浏览器检查。这是明确降级策略，不是 Linux、macOS 或 ARM 原生转换已通过实机验收的声明。公开 HTTP 状态和失败码仍按 [API](API.md#office-文件预览)投影。

Windows x64 原生引擎需要 Microsoft Visual C++ v14 x64 运行库。仅在该平台缺少或加载失败时，按 [Microsoft 官方说明](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)安装或修复，再在独立候选中重新执行 `node scripts/install-office-preview.cjs --require-available`。完整性失败应先核对锁定安装和来源，使用统一安装入口修复，不手动替换引擎 DLL；运行时不会自行下载安装组件或执行系统提权安装。

转换使用后端系统可用字体，缺失时尽可能显示字体提示。安装所需字体后，显式点击“刷新预览”以重新检测并切换引擎／字体代际；普通再次打开可能复用已验证缓存。刷新繁忙时等待当前任务实际结束再重试。字体提示不是全部字形或排版的完整证明，最终版面仍需目标办公软件实机核验。

本功能的验收入口和真实／模拟链路边界见 [E2E 导航](development/E2E.md)。当前实施按用户选择只做桌面 Chromium 验收；移动端、其他操作系统、Word／WPS 最终版式以及实际安装新字体后的效果分别记录，不从源码、合成样本或桌面结果推断通过。
