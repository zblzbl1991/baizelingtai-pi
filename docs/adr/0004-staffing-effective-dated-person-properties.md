# 人员属性按生效日期解释

状态：设计已确认，待实现。2026-10-23 人员管理界面改版访谈中确认。

人员所属事业部、直签身份的真实变化按生效日期保留此前状态，用人日期落在生效日前时沿用当时属性；姓名纠错直接更新并保留修改历史，人员编号保持不变。相较仅保存当前属性，这增加了记录和逐日期判断的复杂度，但避免一次资料编辑把过去项目的直签覆盖或人员归属按现状重新解释。

人员停用及恢复同样指定生效日期。停用期间保留原安排和占用，但不计入项目有效覆盖；恢复不复活已经释放的安排。转事业部保留既有预占及正式安排效力，新方案按用人期间归属检查，跨事业部仍需具体方案许可。台账变化后保留旧方案供对比，重新检查并由用户确认，不自动换人或提交。

旧台账按当前登记值接续为基线，明确此前真实生效日期未知，不从保存或导出时间推断历史；证据不足的历史覆盖标为未核实。新版 Excel 保存人员状态及属性生效记录，旧版引起的属性变化须明确生效日期并经差异确认，缺失字段不清除历史或恢复停用人员。普通属性变更从今天或未来生效；历史纠错明确日期范围、原因和影响后确认，保留原记录及已保存报告版本。

这项决定确立时间语义，不选定存储结构。实施范围及后续交互见[设计讨论](../development/design/staffing.md#2026-10-23-管理界面改版讨论)；已有模块台账事实来源决定保持有效。
