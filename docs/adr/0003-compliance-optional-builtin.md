# 合规审查作为可开关的内置能力交付

状态：设计决定已确认，功能未实现。

合规审查需要业务数据保存、资料处理与 Pi 工具和 Skill 配套，因此随白泽灵台提供业务模块与能力包，初期随应用统一更新。用户显式启用后使用，并可通过开关禁用涉及的功能；这样可统一管理功能可用性与配套版本，避免用户分别安装和配置各项资源。

开关作用于当前实例全部工作目录，初始关闭，启用不自动执行检查。执行期间请求禁用时停止新增任务，在当前步骤实际结束后暂停检查并保留进度，之前显示停用中；重新启用后由用户选择是否继续。

禁用保留档案、资料、检查结果和修正记录，已保存到成果中心的报告继续可查看，数据清理另行操作。现有 Pi 资源过滤不能单独替代业务执行检查；已有会话的资源投影与生效方式仍待细化。

设置入口与人员调配共用，两项能力独立开关并分别管理业务数据。首次启用提供专用智能体、四个 Skill、工具和模型能力的配置引导，再次启用核对并沿用已有配置；合规工具与 Skill 默认仅向专用合规智能体开放，普通聊天保留报告查看和进入该智能体的入口。

普通聊天不新增本能力的提示说明、工具定义或 Skill 索引，验收核对实际模型请求；已有原生聊天历史继续保留。升级保留用户对专用智能体名称与行为说明的修改，内置 Skill 和规则包统一管理，个人扩展单独保存，旧批次保持当时的规则版本。
