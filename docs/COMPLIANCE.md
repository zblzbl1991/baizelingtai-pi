# 合规审查

当前源码支持启用合规审查、绑定专用助手、选择模型和保存工程项目档案。源码完成不表示运行实例已经部署。本阶段尚未提供资料导入、规则执行、人工复核确认和报告导出。

## 开始使用

1. 打开“设置 → 内置能力”，勾选“启用合规审查”。
2. 选择对话模型。可创建专用助手，也可明确关联已有助手身份。资料识别模型可暂不配置。
3. 保存设置。启用和保存不会发起检查或识别请求。
4. 选择工作目录，点击“打开合规对话”。在该聊天中使用“工程项目档案”，或请助手通过 `compliance_project` 建立档案。

一个专用助手负责四个 Skill：资料整理、合规检查、问题复核和报告生成。当前尚未提供的工具会明确显示不可用，Skill 说明不代表对应业务已经执行。普通聊天在资源发现前排除这些资源，不新增合规工具定义、Skill 索引或说明。子 Agent 不继承专用会话资格。

## 工程项目档案

档案具有独立稳定编号。项目名称、业务编号、单位、年度、期次、项目类型和项目阶段分别保存。缺少的字段保留未知。审查人员核对项目身份，并逐项选择四组规则是适用、不适用或尚未确认。

保存使用当前修订和稳定操作编号。重复提交相同内容返回原回执；同一编号换成其他内容会被拒绝。其他聊天已经更改记录时，需要重新核对。档案独立于聊天保存，聊天正文继续由 Pi 原生会话管理。

## 停用和恢复

能力默认关闭。停用保留档案、绑定和模型配置；再次启用复用同一个助手，保留用户修改的名称和行为说明。可在“助手身份”中编辑这两项内容。

已有运行实例应在空闲时重载资源。服务器会拒绝停用后的合规工具调用。未确认的网络结果先查询原操作，浏览器不会自动重发未知写入。首次配置的助手绑定有持久准备记录，可按原操作继续核对。原生会话创建有独立操作标记，重试先查原生记录，结果不确定时不会再创建一个聊天。

状态保存在实际 Agent 身份目录下受保护的 `pivane-compliance/` 中。请把该目录视为用户数据，随身份一起备份。容量限制为五百个工程项目、一万个操作回执、八 MiB 账本。达到限制时明确拒绝保存。
