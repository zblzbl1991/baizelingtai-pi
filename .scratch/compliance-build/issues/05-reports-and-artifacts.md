# 05：导出批次报告并保存到成果中心

**Spec:** [合规审查实现规格草案](../spec.md)

**What to build:** 用户从指定批次按需生成 HTML 详细报告和 Excel 检查清单，在聊天中预览、下载并明确保存到独立成果中心，保留版本与复核状态。

**Blocked by:** [导入文本资料并完成四组规则检查](02-import-and-check.md)。

**Status:** ready-for-agent

- [ ] 文件绑定固定的批次修订和规则版本，带生成时间、字段精度、证据及复核状态。
- [ ] 完整列出问题、证据不足、不适用和执行失败，允许明确标识的未复核报告，不把导出等同于全部通过。
- [ ] HTML 使用安全文本与受限制预览，XLSX 使用固定表头和明确值，可重新上传为文档附件后由已有读取接口核对；不以私密报告路径或成果 ID 直接绕过读取资格。
- [ ] 生成、交付与已保存分别显示；原生交付引用由唯一受管 worker 登记，成果入库继续核对来源资格。
- [ ] 不通过私密文件路径绕过文件权限，重复导出不覆盖旧文件，保存失败不修改批次结论。
- [ ] 已保存成果在能力禁用或来源会话删除后仍可按现有成果权限查看。
- [ ] 从专用聊天生成到预览、下载、保存的端到端流程在桌面和手机通过相关验证。
