# 04：通过确认卡修正字段并确认结论

**Spec:** [合规审查实现规格草案](../spec.md)

**What to build:** 用户从问题打开证据，通过聊天确认卡提交字段修正、重新计算相关规则，并明确确认所选结论，保留前后依据和操作记录。

**Blocked by:** [导入文本资料并完成四组规则检查](02-import-and-check.md)、[识别扫描资料并支持预算暂停与恢复](03-scans-budget-and-recovery.md)。

**Status:** ready-for-agent

- [ ] 卡片显示工程项目、检查批次、具体原值与新值或确认范围，包含原文证据和修正理由。
- [ ] 只有实际工作台用户操作可提交人工确认，智能体工具只能准备方案及查询结果。
- [ ] 服务端提交前检查当前修订、资料和规则版本、来源及能力状态；旧卡片要求重新核对。
- [ ] 同 ID 同参数返回原操作结果，异参数拒绝；两个聊天竞争同一修订时最多一个成功。
- [ ] 断线后可以查询回执，失败或不确定结果不自动重放，不部分覆盖其他修正。
- [ ] 字段修正重算受影响规则，新修订的复核状态与旧历史分开，原识别值及确认记录保留。
- [ ] 在公开接口、真实工具和桌面/手机上完成证据查看、准备、确认、重算和回执查询。
