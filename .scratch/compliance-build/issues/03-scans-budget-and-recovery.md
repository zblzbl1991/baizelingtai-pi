# 03：识别扫描资料并支持预算暂停与恢复

**Spec:** [合规审查实现规格草案](../spec.md)

**What to build:** 用户对扫描 PDF 和图片执行资料识别，取得带出处的字段并参与四组规则检查；用户能查看预算、暂停原因和确定可继续的步骤。

**Blocked by:** [导入文本资料并完成四组规则检查](02-import-and-check.md)。

**Status:** done (source verified; not deployed or released)

- [x] PDF 页在隔离、无凭据的解析进程中按需渲染；缺少原生渲染能力时明确报告，不能伪装识别成功。
- [x] 图像签名、像素、页数与传输量有界，模型只接收授权资料及必要页面，输出经 schema 校验。
- [x] 实际模型支持图像输入，缺少配置或模型不可用时保留文本检查并列明扫描项原因。
- [x] 按批次限制处理量、模型调用和运行时间，可取得用量与费用时记录，未知费用显示未知。
- [x] 达到预算或停用请求后停止安排下一步，当前步骤实际结束后保存检查点；超时不冒充取消或空闲。
- [x] 网页断开不重复提交，服务重启后的执行中请求列为待核对；用户可选择继续确定未完成项。
- [x] HTTP、真实合成模型请求与浏览器中均能观察成功、配置缺失、预算暂停及中断恢复。
