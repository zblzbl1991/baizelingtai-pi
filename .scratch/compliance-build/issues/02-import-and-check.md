# 02：导入文本资料并完成四组规则检查

**Spec:** [合规审查实现规格草案](../spec.md)

**What to build:** 用户从聊天附件或已授权目录导入文本资料与台账，核对归属及资料角色，创建批次，执行四组检查并在聊天中查看带原文位置的结果。原件变化后仍能追溯本次使用内容。

**Blocked by:** [启用能力并建立首个工程项目档案](01-enable-and-project.md)。

**Status:** ready-for-agent

- [ ] 接收受支持的 PDF、图片、XLSX 和 UTF-8 CSV，扫描内容在识别能力尚不可用时明确列为无法判断；不支持的格式提示转换。
- [ ] 导入范围与文件身份可核对，快照不可变，重复导入、同类多份和归属冲突有明确结果。
- [ ] 项目身份和适用清单由用户核对，缺失资料、证据不足、不适用与执行失败分别显示。
- [ ] 四组规则覆盖文号与日期精度，固定样例验证零、三十、三十一日、提前签订、同日及月份范围。
- [ ] 批次保存实际资料与规则版本，按需查询明细和证据；结果 UI 不将未检查显示为通过。
- [ ] 公开接口、专用工具及桌面/手机流程可从导入走到首份结果，且符合既有文件安全与容量预算。
