# 01：启用能力并建立首个工程项目档案

**Spec:** [合规审查实现规格草案](../spec.md)

**What to build:** 用户在内置能力设置中启用合规审查，完成专用智能体和模型的首次配置，通过专用聊天建立工程项目档案，并能重开后继续使用。业务状态、受管工具、设置 UI 和公开接口形成首条可验证流程。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 默认关闭；实例开关覆盖入口与服务端执行资格，启用不发起检查。
- [ ] 首次配置持久绑定专用档案，再次配置不重复创建，用户名称与行为说明保留。
- [ ] 普通聊天不新增合规提示、Skill 索引和工具定义，专用会话资格经过真实绑定验证。
- [ ] 用户可以建立与读取稳定 ID 的工程项目档案，包含已确认身份、类型、阶段及适用清单，未知字段保留未知。
- [ ] 受保护私密状态使用修订与稳定操作 ID，重开服务可读取，失败不报告成功。
- [ ] 专用工具、四个 Skill、设置和档案操作通过 HTTP、真实 RPC 与桌面/手机的相关验证。
