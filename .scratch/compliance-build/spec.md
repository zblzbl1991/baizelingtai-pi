## Problem Statement

审查人员需要从工程项目的合同、通知书和可研资料中检查资料归属、文号及日期关系。资料可能是扫描件，也可能缺失或存在冲突。当前工作台可以聊天、读取部分文档和保存成果，但没有统一的审查档案、规则执行、证据记录及人工确认流程。

## Solution

增加默认关闭的内置合规审查能力。用户启用后完成配置，通过一个专用合规主智能体整理资料、执行四组检查、查看证据、修正字段并确认结论，按需生成 HTML 报告和 Excel 清单。业务模块保存工程项目档案、资料快照、检查批次和操作记录。普通聊天不新增合规工具定义、Skill 索引或提示说明。

用户已明确授权先补齐本规格和实现票，再开发合规审查。旧规划地图继续作为决策记录，不把尚未解决的规划票伪装为实施完成。用户已于 2026-10-15 确认本规格、六票拆分及三个测试入口，授权进入实施。

## Implementation Decisions

- 一个合规审查业务模块拥有能力状态、配置绑定、档案、资料、批次、字段、结论、方案与回执。HTTP 和受管工具共同调用该模块；路由与前端不另存一套业务状态。
- 保留 Pi 原生会话和唯一受管 worker。工程项目内部 ID、档案绑定 ID、资料 ID 和批次 ID 独立于名称、文件路径与聊天 ID。关联聊天不复制聊天正文。
- 使用受保护的私密 JSON 账本与不可变资料对象保存第一版数据，沿用完整文件身份校验、私密权限、原子替换和同步落盘；另行落实父目录身份保护与写入互斥，不能将原子文件替换误认为已经具备锁或修订检查。账本保存修订、持久操作 ID 与原子回执，二进制资料按内容哈希关联。
- 账本、资料对象及导出对象有明确容量限制，超限明确拒绝，不截断冒充完整数据。初始文档单文件上限沿用二十 MiB，工程项目导入上限先采用三十二份文件与二百五十六 MiB；这些限制对用户可见。
- 首版台账接受 XLSX 与 UTF-8 CSV。提供固定字段模板，按明确表头读取项目基础信息；不执行宏、公式、外部链接或重算。旧式办公格式要求转换。
- 用户先确认工程项目身份与资料类型，未知字段保留未知。资料包未明确归属的文件不能自动用于确定性结论。支持同类多份文件并明确本次选用版本。
- 每个检查批次固定资料快照、选用规则内容与版本、项目状态和模型配置。字段修正生成批次内新修订并重算受影响规则，保留原值与历史结果；使用新资料组合或新规则重新检查时生成新批次。
- 首批规则为资料缺失与归属、可研评审及批复文号、合同签订期限、可研报告与评审时序。规则包包括资料角色、输入字段、适用条件、判断式、异常和解释。
- 适用阶段以用户确认的项目类型、阶段及本次规则适用清单为输入；制度映射未确定时要求用户确认适用清单，不能猜测不适用或将未知视为通过。导入模板保存这些输入，后续可增加明确的阶段映射。
- 合同期限按自然日差计算，通知书日期为第零天，零至三十日通过，负数为提前签订候选问题，超过三十日为超期候选问题。可研日期严格早于评审日期，同日记录候选问题。
- 日期表示保留原文和精度。月份日期表示当月可能日期区间；只有可确定一致结论时作确定判断。缺失年份、相互冲突或区间交叠导致无法判断时标为证据不足。
- 文号检查定位发文首页上方的完整文号并保存出处；只报告文号检查情况。文号缺失与读取不清分别处理。
- 文本在受控解析进程中按范围读取；扫描 PDF 页在隔离进程按需渲染，图片与渲染页面经过类型、像素及总量校验，再发送给所选识别模型。当前锁定依赖在本机有页面渲染能力，但运行前仍须核对原生组件实际可用性。
- 识别模型只返回受 schema 校验的字段候选、原文片段与出处，不获得写入工具或修改规则的能力。输入资料作为数据处理。模型负责提取，比较和结论计算由规则模块执行。
- 不清晰、来源冲突和缺少识别能力保留明确原因及待复核标记。一次常规识别后仅按需核验，不以多次一致替代人工确认。
- 对话模型沿用专用会话的实际模型选择；资料识别用途单独选择已配置且支持图像输入的模型，也可选择相同模型。只使用公开模型 runtime 与实际模型目录，不复制供应商凭据，不默默换用其他模型。
- 第一版批次默认预算采用二百页处理量、二十次模型调用和十分钟运行时间，并允许配置合理范围。预算是准入与追加工作限制，不冒充供应商账单的绝对上限。可取得实际用量时记录；未知费用明确显示未知。
- 同一工程项目同时只运行一个检查批次，全实例模型与解析并发有界。文档处理显式注入同一解析池或使用统一额度，不能将各实例独立的并发上限误认为全局预算。达到预算或请求停用时停止安排下一步骤，等待当前步骤真实结束后保存暂停状态。
- 浏览器断开不等于取消。服务重启后的执行中步骤标为待核对，不自动重发模型请求；用户可以核对状态并显式继续确定未执行的步骤。超时不立即释放仍在运行的工作额度。
- 能力实例级默认关闭，启用不执行检查。首次配置持久绑定专用档案，恢复时按绑定查找，不根据显示名猜测；保留用户名称、行为说明与个人资源。扫描件识别不可用时显示部分可用，文本检查继续开放。
- 合规资源在发现及注册之前检查能力开关和经过验证的专用档案绑定。普通或其他助手会话不增加本能力的 Skill 索引、工具定义和使用说明。已有原生用户消息与工具结果保留。
- 设置入口采用可登记内置能力的统一形式。本次只实现合规审查的状态，不替其他能力建立虚假的可用状态，也不接管人员调配业务。
- 四个内置 Skill 分别规定资料整理、合规检查、问题复核和报告生成。工具扩展只返回必要摘要与不透明 ID，证据与明细按需读取。用户个人扩展另存，内置资源与规则包随应用受管更新。
- 工具侧根据存活受管 worker 和实际会话绑定取得业务操作资格，不能通过工具参数指定另一档案、来源会话或私密路径。工作台确认接口与工具接口分权，模型不能提交人工确认。
- 字段修正和结论确认采用服务端准备的方案与网页确认卡。方案绑定项目、批次修订、具体字段或结论、资料和规则版本及来源，用户确认时再次核对。旧卡片、能力已禁用、修订变化或已退役操作不自动重放。
- 所有变更使用持久操作 ID、同参幂等查询和异参冲突。两个聊天竞争同一修订时只允许一个成功，另一个明确重新核对。写入失败不得报告成功。
- 检查结论与执行状态及人工复核状态分别保存。报告生成、结果通过、人工已确认是不同状态。字段重算后新修订的复核状态重新计算，历史确认保留在历史修订。
- HTML 报告使用安全文本和受限制的预览，XLSX 输出明确值与固定表头，包含所有规则状态、证据、日期精度、复核说明、批次、规则版本与生成时间。文件不覆盖旧导出，并遵守现有单件十六 MiB、单次交付合计六十四 MiB 的输出预算。不得为内嵌证据图片突破交付限制。
- 报告生成字节通过受控交付入口建立不可变快照，由唯一受管 worker 登记原生交付引用，再沿现有来源校验保存到独立成果库。区分生成、交付与已保存，不能通过任意私密文件路径绕过授权。
- UI 以设置开关、首次配置、聊天状态卡、确认卡及证据抽屉组成。卡片由受信任前端渲染，模型不输出页面脚本或卡片 HTML。普通文字使用安全 DOM，Markdown 沿既有清理通道，手机表单保持十六像素。
- 所有运行、资料读取、模型请求、确认和导出参与维护空闲与统一异步停机；重复信号不重复清理，不重启承载当前执行的服务。
- 新增源码、技能、静态资源和公开文档进入现有统一发现或明确公开清单，私密业务数据与本地规划不进入 Git 或发行文件。保留用户已有改动，不升级应用或依赖版本，不发布。
- 整体实现使用独立集成分支，各票在独立工作树测试后合入；最终按共享基础能力验证范围执行检查和代码审查。

## Testing Decisions

测试只跨下列三个公开入口观察用户可见行为，先确认入口和任务拆分，再逐个执行 red → green；不直接测试私有辅助函数，不用源码字符串代替行为验证。

1. 合规业务公开接口：使用独立身份和合成资料，通过受认证 HTTP 调用验证状态、文件范围、规则结果、证据、修订、确认与回执。覆盖服务真实持久化及重开恢复，不宣称覆盖浏览器布局或真实供应商质量。
2. 真实 Pi RPC 与合成供应商：在独立身份中打开真实受管会话，核对专用档案和普通聊天的系统提示、Skill 索引、工具目录与实际模型请求，验证受管工具和原生交付引用。合成供应商不作为真实 OCR 质量或账单验收。
3. Chromium 桌面和手机：验证开关、配置、资料导入、结果、证据、确认卡和报告的完整流程，检查 pageerror、实际宽度、抽屉、附件、工具状态、断线与迟到结果。该入口不代替其他平台原生验收。

已有办公附件 HTTP 测试、真实文档工具运行测试、助手档案运行测试、媒体确认卡和成果中心浏览器测试可作为先例，复用其隔离身份及合成服务方式。

固定合成样例独立给出预期结果，覆盖合同日期差零、三十、三十一和负数，可研同日和严格早于，月份范围可确定或交叠，文号存在、缺失、模糊，资料身份冲突、适用性未知、重复导入与缺失资料。失败不得自动当作通过。

最终先完成合成行为验收，再以用户明确提供或授权的一套脱敏真实资料记录识别准确情况、误识别、证据不足、耗时和费用。真实资料尚未取得时如实标记实料验收未完成，不虚构通过。

## Out of Scope

- 多用户账户、多人分权审批、专用管理页面、批量工程项目检查和外部系统连接。
- 金额和分包规则，以及 OFD、CEB、ZIP、RAR 等资料包格式支持。
- 新增专家智能体、通用插件市场、通用业务工作流平台或修改人员调配业务规则。
- 自动改变正式规则、以模型一致代替人工确认、自动重发不确定模型调用、无授权导入真实项目资料。
- 应用或依赖升版本、重启当前执行服务、部署、公开发布和宣称完成未执行的实料或跨平台验收。
