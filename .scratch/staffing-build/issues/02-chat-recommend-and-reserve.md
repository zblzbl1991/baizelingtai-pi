# 在专用聊天推荐人员并通过卡片预占

**What to build:** 用户在专用聊天提出项目需求，得到真实推荐名单，调整后通过卡片预占或正式确认，并看到人数及直签缺口。

**Blocked by:** 启用人员调配并建立初始台账。

**Status:** ready-for-agent

- [ ] 专用 Skill 和工具仅对已验证专用会话加载，普通会话无新增人员调配上下文。
- [ ] 推荐按全程可用和近九十天工作天数排序，历史不足明确提示。
- [ ] 卡片绑定人员、日期、台账修订和当前跨事业部许可。
- [ ] 真实确认后再次检查，两个聊天不能重复占用同一人。
- [ ] 断线、重复操作和不确定结果通过原操作 ID 核对。
- [ ] 公开 HTTP、受管会话输入与浏览器关键路径先红后绿。
