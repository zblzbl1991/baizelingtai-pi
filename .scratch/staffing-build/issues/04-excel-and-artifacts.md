# 导入 Excel 差异并按需保存成果

**What to build:** 用户导入标准 Excel 核对人员与占用差异；按需导出带版本的 Excel，并保存到独立成果中心。

**Blocked by:** 在专用聊天推荐人员并通过卡片预占。

**Status:** ready-for-agent

- [ ] 有合成标准模板，原件有预算安全读取，不执行公式或宏。
- [ ] ID、重名、日期和旧版本差异明确，未确认不改台账。
- [ ] 导出绑定一致台账版本，工作表和值可往返核对。
- [ ] 生成、交付和独立保存状态分别报告，沿用来源授权。
- [ ] 保存成果失败不误报成功，不撤回已成功人员安排。
