## 1. 认识工作台

打开实例地址后，左侧是全局导航，中间是工作区：

- **工作**：按服务器真实目录管理对话线程（主要工作区）。
- **助手**：按助手身份和项目分类管理对话。
- **定时**：周期/单次定时任务。
- **成果**：跨会话查看明确交付和媒体结果。
- **身份**：创建和管理助手身份。
- **扩展**：扩展发现、微信消息渠道、已安装资源与 MCP。
- 左下角齿轮：**工作台设置**（供应商模型、偏好、版本等）。

![项目工作区总览](assets/02-项目工作区.png)

每个项目对话页右侧还有一列工具：**详情、文件、历史、侧聊**，分别打开对应侧栏（见第 5、6 节）。

## 2. 开始第一项工作

1. **打开项目**：点击「新聊天」旁的文件夹图标（或起始页的「打开服务器目录」）。注意：目录在**部署白泽灵台的服务器**上，不是你面前浏览器的电脑。弹窗中可输入绝对路径、逐级浏览、**新建文件夹**（支持中文和空格，一次创建一级），最近项目会保留在下方便于回访。

   ![新建文件夹](assets/23-新建文件夹.png)

2. **新聊天**：进入项目后点「+ 新聊天」。
3. **发送第一条消息**：在底部输入框输入，回车或点发送箭头。未打开会话时输入框不可用；会话加载完成后模型名和思考等级会显示在输入框下方。
4. 首轮有效问答后，线程会**自动命名**（也可在线程菜单手动重命名）。

![对话与回复](assets/04-对话回复.png)

回复支持完整的 Markdown：标题、列表、表格、代码块、数学公式、Mermaid 图。每条回复下方有**复制、朗读、分叉**按钮和时间；用户消息悬停可复制或编辑重发。

## 3. 模型与思考等级

点击输入框下方的**模型名称**打开选择面板：

- 支持按名称、ID、供应商搜索；
- **星标**收藏常用模型（跨设备同步），最近使用保存在当前浏览器；
- 「查看全部模型」展开供应商分组的完整目录。

![模型面板](assets/05-模型面板.png)

旁边的**思考**下拉选择推理等级（不启用/低/中/高等，取决于模型能力）。带 Fast/Ultrafast 速度的渠道会额外显示速度档位。切换模型或思考等级需要会话**空闲**。

> 模型从哪里来？在「工作台设置 → 供应商与模型」完成 API Key 或 OAuth 认证后，目录中对应模型才可用。详见第 13 节。

## 4. 对话输入全攻略

### 4.1 输入框与「+」菜单

点击输入框左侧 **+** 打开「添加操作」菜单：

![添加操作菜单](assets/07-添加操作菜单.png)

- **添加附件**：上传图片、文档、表格、代码文件。持久线程支持现代 Office / 旧 DOC·XLS·PPT / PDF 原件，单份 ≤ 20 MiB、单条 ≤ 5 份；文件卡片可下载原件，六种 Office 格式可近似预览。
- **附件管理**：查看原件占用与清理选项。
- **运行中消息投递方式**：任务运行中发消息可选 **引导**（本轮工具后立即送达）或 **后续**（当前任务完成后送达）。空草稿显示停止按钮；有内容时显示发送。
- **延迟发送**：指定时间发送。
- **创建定时任务**：为当前线程安排周期任务（见第 9 节）。
- **添加能力…**：让扩展助手帮你查找、安装技能。

### 4.2 快捷语法

| 输入 | 作用 |
|---|---|
| `@文件名` | 插入服务器项目文件路径，Agent 会按需读取 |
| `!命令` | 在服务器执行 Shell，输出进入对话 |
| `!!命令` | 执行但不进入后续模型上下文（仍保留原生执行记录） |

**语音输入**：点击麦克风录音，再点一次结束并转录，文字进入可编辑草稿。录音最长 2 分钟，需 HTTPS 或 localhost；音频会上传所选服务并可能收费。

### 4.3 消息显示模式

「工作台设置 → 使用偏好 → 消息显示」可选 **简洁**（保留最终回复，过程可展开）/ **正文** / **完整记录**（逐条查看，适合排障）。也可开启「显示回复请求平均速度」，最终回复下方显示 `请求平均 ≈ … tok/s`。

### 4.4 多轮对话

同一线程内连续追问即可，Agent 始终带着当前项目的上下文；上下文占用显示在顶部，接近上限时压缩或开新线程。

![多轮对话](assets/06-多轮对话.png)

### 4.5 任务进度与子 Agent

- 多步骤任务可在输入框上方出现**当前进度**卡，点击展开步骤（进度由 Agent 报告）。
- 明确让主 Agent 委派任务时，输入框上方出现**子 Agent** 面板，显示状态、模型、用量，可引导、停止或继续；结果默认折叠。
- 说「新开一个线程做这件事」，Agent 可创建同项目的**任务线程**并立即执行；也可以让线程之间直接互相留言。

### 4.6 选中文字继续讨论

选中回复正文会出现浮层：**加入主对话**（作为引用插入输入框）、**在侧聊中提问**、**朗读选区**。引用不会自动发送。

![选中文字与侧聊](assets/13-选中文字.png)

## 5. 会话详情与上下文管理

点击右侧工具栏「详情」：

![详情面板](assets/08-详情面板.png)

- **运行状态**与所用模型（如 demo/lingtai-chat）；
- **查看系统提示词**：查看当前对话实际生效的提示词及来源；
- **上下文占用**：当前消耗 / 窗口上限，可手动**压缩上下文**（也可让 Agent 自动压缩；压缩后较早问答在正文顶部「上下文已压缩」标记上方仍可回看）；
- **会话累计用量**：输入/输出 Token、缓存读取、费用；
- 折叠区：运行设置、会话信息、当前加载的资源。

## 6. 历史、文件与侧聊

### 6.1 历史面板

![历史面板](assets/11-历史面板.png)

支持**搜索**与会话**树**两种模式；可加书签（Pi 原生标签，终端 `/tree` 同样可见）、查看分支、**分叉**、恢复对话位置。注意：恢复历史不会撤销已发生的文件修改或命令。正文左侧的**对话目录**刻度条可悬停预览、点击跳转、一键加书签。导出：HTML 用于阅读，JSONL 导出当前活动分支。

### 6.2 文件面板与查看器

![文件面板](assets/09-文件面板.png)

可浏览项目与关联目录、搜索路径；点击文件在**文件查看器**中阅读：

![文件查看器](assets/10-文件查看器.png)

- Markdown 渲染、代码高亮、公式；Office 六格式近似预览；PDF 保留页码缩放；
- 图片/SVG 可缩放拖动；单文件限额 16 MiB；
- 「本轮文件 / 当前文件 / 交付物」区分不同来源；需要稳定交付时让 Agent 用 `deliver_files` 交付，成品同时进入成果中心。

### 6.3 侧聊（BTW）

点击右侧「侧聊」围绕当前背景另开讨论：首次发送会**冻结主聊背景**；可单独选模型；修改文件与执行命令需要侧聊内本次回复的确认。空闲 12 小时释放运行资源；刷新或关页会结束临时侧聊，重要内容先复制回主聊。

![侧聊面板](assets/12-侧聊.png)

## 7. 线程管理

- **项目 / 动态**两个视图：「项目」按目录浏览线程；「动态」集中显示正在运行、需处理和最近会话。
  ![动态视图](assets/14-动态视图.png)
- 列表搜索匹配标题及首条问题；底部「搜正文」跨线程全文搜索；`Ctrl/Cmd+K` 聚焦列表搜索。
- 线程行 **⋯ 菜单**：重命名、重新生成标题、归档、移动到其他项目、删除等。
  ![线程菜单](assets/15-线程菜单.png)
- **归档**只整理显示不删数据；**移动线程**保留会话 ID、完整历史与书签（仅限空闲普通线程，阻碍会在预览中列出）。
- 左栏宽度可拖拽调整；「定位当前线程」快速回到正在查看的线程。

## 8. 助手身份（五页工作区）

「身份」页管理助手身份：每个身份有独立的 SOUL（行为）/ USER（偏好）/ MEMORY（记忆）文件，普通工作对话新线程不绑定身份。

![助手身份页](assets/18-助手身份页.png)

点「新建」进入五页工作区：

![新建身份：设定页](assets/19-新建身份.png)

- **概览**：身份总览与入口；
  ![身份概览](assets/20-身份概览.png)
- **设定**：基本信息（名称、描述）、能力开关（启用身份、长期记忆、已学习技能）、个性与行为（编辑 SOUL，支持预览与示例模板）；
- **记忆**：查看/管理 MEMORY 与 USER 内容；
  ![身份记忆](assets/21-身份记忆.png)
- **技能**：管理该身份积累的技能；
  ![身份技能](assets/22-身份技能.png)
- **学习**：后台学习开关与提示反馈、整理合并方案（先生成方案，逐组确认后应用，不自动删除）。
  ![身份学习](assets/23-身份学习.png)

创建后到「**助手**」页：选择身份 → 选择项目分类 → 新聊天。对话回复会以身份名称署名。

![助手对话](assets/24-助手对话.png)

> 注意：身份不是安全沙箱——分类可复用同一服务器目录，文件与按物理目录划分的记忆仍共享。

## 9. 定时任务

「定时」页安排周期或单次工作：

![定时任务页](assets/16-定时任务页.png)

- 目标可以是**指定线程**或**身份主线程**；也可从输入框 + 菜单「创建定时任务」直接挂到当前线程。
- 启用前核对：时区、下一次执行时间、预算、错过处理策略。
- **暂停计划**与**停止本次运行**是不同操作。服务器须持续运行任务才会触发。

## 10. 成果中心

「成果」页跨会话查看明确交付（`deliver_files`）和媒体结果：

![成果中心](assets/17-成果中心.png)

支持预览、下载与按会话回溯；慢任务（如视频）取回的结果也会集中在这里。

## 11. 扩展、微信渠道与 MCP

「扩展」页四个标签：

### 发现

精选能力目录，按类型（扩展包/技能/消息渠道/MCP）和安装状态筛选；卡片展示用途、来源、版本与「使用前提与示例」。**浏览不会安装任何内容**；「让助手帮我找」把需求交给扩展助手。

![扩展发现](assets/25-扩展发现.png)

内置能力（搜索与阅读网页、操作桌面应用、制作演示文稿、人员调配等）标为「白泽灵台内置」，无需另装。

### 消息渠道（微信）

顶部汇总组件、账号、绑定与需处理消息；按「安装组件 → 扫码 → 绑定线程」逐步引导。支持文字与图片私聊、文件回传、斜杠指令和定时通知；线程菜单的「连接微信…」可带入目标线程。

![消息渠道](assets/26-消息渠道.png)

### 已安装

按 Packages、技能、扩展模块、模板/主题筛选；行内启用/停用；「检查更新」手动联网查询，更新、移除、恢复继承在 ⋯ 菜单。安装前核对来源与代码执行影响。

![已安装](assets/27-已安装.png)

### MCP

编辑全局或受信项目的 MCP 配置；保存与连接/重载分开；查看状态、重连和 OAuth 使用已打开的持久线程。旧 MCP 适配器迁移须停机备份。

![MCP 设置](assets/28-MCP.png)

> 已安装 ≠ 当前会话已加载；配置完成后等会话空闲重载并核对。项目未受信时不能写项目配置。

## 12. 人员调配

可选的人员台账与调配功能（发现页亦可达）：启用后建立**专用智能体**，普通聊天保持原有配置；停用后保留台账和历史。

![人员调配](assets/29-人员调配.png)

启用流程：上传/建立人员台账（Excel）→ 核对当前与未来占用 → 在对话中安排人员并经卡片确认。详见 [人员调配文档](../docs/STAFFING.md)。

## 13. 设置详解

点击左下角齿轮进入「工作台设置」，左侧分类：

### 供应商与模型

![供应商与模型](assets/31-供应商与模型.png)

展开供应商 → 登录（OAuth）或填写 API Key → 启用所需模型。测试按钮会发送少量付费请求。可自定义 Provider 与模型。**不要把凭据发到聊天里**。

### 模型与能力

![模型与能力](assets/33-模型与能力.png)

子 Agent 默认模型与角色、语音（ASR）服务等按用途配置；多模态与媒体入口的显隐也在这里管理。

### 内置能力

![内置能力](assets/39-内置能力.png)

查看内置子 Agent、记忆组件等随应用分发的能力包及其启停。

### 使用偏好

![使用偏好](assets/32-使用偏好.png)

- **外观**：主题（跟随系统/晴空/薄荷/雾蓝/丁香/夜间）、字号，保存在当前浏览器；
- **消息显示**：简洁/正文/完整记录、平均速度显示；
- **辅助模型**：会话标题、媒体规划、后台学习各用哪个模型（「自动」跟随线程；后台学习需专用模型）；
- **界面语言**：简体中文 / English，切换立即刷新（未发送草稿会保留）。

### 系统提示词

![系统提示词](assets/34-系统提示词.png)

对所有项目或当前项目编辑要求；**项目要求替代通用要求，不自动叠加**。对话空闲后点「更新当前对话」加载；「查看当前对话」核对实际生效内容。

### 运行配置（Pi 原生设置）

![运行配置](assets/35-运行配置.png)

管理 Pi 原生资源：Packages、Skills、SkillHub 来源、受信项目等底层配置。

### 用量统计

![用量统计](assets/38-用量统计.png)

按会话/模型汇总输入输出与费用（数据来自原生消息记录）。

### 版本与更新

![版本与更新](assets/36-版本与更新.png)

检查白泽灵台与 Pi 版本；**不自动安装**。需要更新时复制独立 Agent 提示词，在部署机器由另一个 Agent 核对兼容性、备份后执行——承载当前会话的服务不能由本会话直接停止。Pi 与白泽灵台成组升级。

### 网络与访问

![网络与访问](assets/37-网络与访问.png)

管理登录验证（Token）、监听范围（本机/其他设备）与代理。**开放其他设备访问前必须先开启登录验证**；监听/代理保存后安全重启生效。

### 媒体接入

![媒体接入](assets/40-媒体接入.png)

添加图片/视频/语音服务地址、凭据与模型协议。新安装没有默认可执行媒体服务。

## 14. 在聊天里生成图片、视频和语音

配置媒体模型后，直接说「给报告画张封面」「把这段话配成语音」。Agent 放置**生成卡片**：出现卡片尚未生成或计费，**点击确认后才执行**。

- 可先改参数；服务器调整参数会再次请你确认。
- 视频建议分阶段：先让 Agent 准备首帧/尾帧/参考图，下一轮再生成视频；慢任务默认等待 2 小时（可设至 24 小时），超时或重启后点「继续查询原任务」取回同一任务，不重复生成。
- 同时确认多张卡片按名额排队（远端最多 4 项、视频 2 项）。
- 结果显示在卡片及实验室历史；失败或结果不明不自动重试。
- 侧聊不提供生成卡片。媒体实验室入口在「设置 → 媒体接入」及发现页。

## 15. 安全、备份与更新

- **凭据**：API Key 只填在「供应商与模型」；聊天凭据不会自动配置媒体服务。记忆与学习功能会拦截疑似凭据和提示词注入。
- **访问控制**：本机访问默认免验证；开放局域网/公网前务必在「网络与访问」开启 Token 登录。远程 OAuth 的 localhost 指服务器。
- **执行边界**：项目范围不是沙箱，只安装可信扩展；`!` Shell 命令在服务器以服务权限执行。停止运行不会撤销已发生的文件修改。
- **备份**：升级/维护前停机备份整个身份目录（默认 `~/.pi/agent`），保留会话 JSONL、媒体与 prompts；不要在服务运行时直接复制或手工改动会话文件。
- **数据范围**：会话与项目在服务器；浏览器 localStorage 只保存界面偏好与最近使用。

## 16. 常见问题

| 现象 | 处理 |
|---|---|
| 模型列表为空 | 未完成供应商认证：到「供应商与模型」配置 Key/OAuth；或实例未配置 `models.json` |
| 「选择项目」找不到目录 | 项目范围由服务器 `PI_PROJECT_ROOTS` 限制，在启动配置调整后空闲重启 |
| 线程一直「运行中」 | 底部状态为准；需要释放运行实例用 `/quit`，切换线程不会立即停止 worker |
| 发送无响应/超时 | 先核对网络与供应商额度；超时不代表取消，先查状态再决定是否重发，勿重复投递 |
| 扩展装了没生效 | 等会话空闲重载；在「已安装」核对启用状态 |
| 忘记访问 Token | 在服务器以同一 Agent 目录执行 `npm run access:reset -- --disable --confirm`（见访问控制文档） |
| 想手机访问 | 支持手机浏览器访问（需 HTTPS 与登录验证），界面自动切换为移动布局；本说明不覆盖移动端细节 |
