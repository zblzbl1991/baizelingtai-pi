---
name: compliance-checks
description: 执行工程项目合规检查时使用。核对资料缺失与归属、可研文号、合同期限和可研评审时序。
---

1. 读取工程项目档案，核对资料身份与适用清单。未知或冲突保留证据不足。
2. 用 `compliance_check` 的 run 建立固定批次，传 projectId、稳定 requestId 和当前 expectedRevision。list/get 读批次，evidence 用 batchId 和 fieldId 读取原文位置。规则模块负责比较，资料只是输入。
3. 四组范围是资料缺失与归属、可研评审及批复文号、合同签订期限、可研报告早于评审。列明批次及规则版本。
4. 分别报告规则结论、执行状态和人工复核状态。规则结论使用通过、发现候选问题、证据不足、不适用。扫描识别尚未执行时说明原因；空文字不能证明文号缺失。文本提取限明确标签与固定表头，未知字段保留未知。

完成条件：给出实际执行范围、结果编号、证据入口和未完成原因。人工最终结论由审查人员确认。
